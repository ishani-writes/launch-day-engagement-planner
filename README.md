# Launch Day Engagement Planner

A daily routine for choosing which Product Hunt launches to upvote and comment on.

## The problem

Launch week runs on reciprocity. Teams that support other launches get support back, but scrolling the daily list for an hour is a poor use of a small team's time. Generic "congrats!" comments don't help anyone.

## What this does

You paste in the day's launches. The prompt sorts them by relevance to your audience, picks the few worth engaging with, and drafts a comment that refers to something specific in each product.

## How to use it

1. Copy the day's launch names and one-line taglines.
2. Fill in your audience at the top of `prompts/daily-triage.md` and paste the list.
3. Read the comments, rewrite anything that sounds off, and post them yourself.

## What's inside

- `prompts/daily-triage.md`: the prompt
